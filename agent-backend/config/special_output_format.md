# 特殊作业评分输出规范

- 只回答当前问题；得分、数量、原因和票据必须来自本轮 Java `18082` 返回。
- 不输出原始 JSON、SQL、内部字段名、工具名、内部 URL 或异常堆栈。
- 总览使用固定标题、总分/满分、通过结论和三个维度得分。
- 单个评分项使用简短段落，不使用表格，包含编号、名称、通过/未通过状态、原因和接口返回的关键事实。
- 三个及以上同类评分项、多个模块或多张问题票才使用简洁表格。
- 无数据时只说“暂未找到可用的评分数据”，不得把无数据写成 0 分。
- 接口失败时只说“当前评分服务暂时不可用，请稍后重试”。
- 多轮会话可以使用历史摘要理解上下文，但当前得分和原因必须重新查询。
