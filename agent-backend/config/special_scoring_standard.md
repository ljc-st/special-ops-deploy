# 特殊作业评分标准（Excel 版）

本文件依据《模块评分内容文档_终版修订版（修改样例）.xlsx》整理，仅用于智能体理解查询意图和组织回答。所有分数、数量、原因和票据明细必须以 Java `18082` 本轮返回为准，模型不得自行计算或补全。

## 评分结构

- 特殊作业模块满分 100 分：功能建设 10 分、数据质量 30 分、应用成效 60 分。
- 编号段与维度对应：`1.x` 功能建设，`2.x` 数据质量，`3.x` 应用成效。
- 评分总览必须输出总分/满分、通过结论和三个维度得分。

## 功能建设（1.x）

- `1.1`：近 2 个月是否存在特殊作业报备数据。
- `1.2`：近 2 个月是否存在特殊作业票数据。
- `1.3`：近 2 个月是否存在特殊作业抽查数据。

## 数据质量（2.x）

- `2.1`：报备和作业票重复数据占比是否均不超过 10%。
- `2.2`：除停产企业外，化工企业报备数据接入率是否达到 100%。
- `2.3`：除停产企业外，化工企业作业票接入率是否达到 100%。
- `2.4`：近半年报备数据关键字段缺失率是否不超过 10%。
- `2.5`：近半年作业票关键字段缺失率是否不超过 10%。
- `2.6`：特级/一级动火视频字段，以及全部作业票经度、纬度字段填写率是否达到要求。

## 应用成效（3.x）

- 报备与作业票应相互对应；报备无票、作业票无报备时，以接口返回的异常项和原因说明。
- 作业票、报备、抽查数据的更新时间和覆盖情况，以接口返回的统计窗口和指标说明为准。
- 应用问题类评分应列出评分项、票据/企业和原因；没有实体时明确说明接口未返回具体票据明细。
- 3.5 及其子项的具体编号、扣分规则和问题票，以 Java 返回的评分配置和实体为准，不根据常识推断。

## 查询与输出约束

- 用户问特殊作业评分、总分、是否通过：调用 `special_score_overview`。
- 用户问特殊作业报备功能建设情况、报备功能或评分项 `1.1`：现场调用 `score_calculate(module=special, dimension=functionBuild, itemNo=1.1)`，不得用总览结果替代。
- 用户问特殊作业票管理功能建设情况、作业票管理功能或评分项 `1.2`：现场调用 `score_calculate(module=special, dimension=functionBuild, itemNo=1.2)`，不得用总览结果替代。
- 用户问特殊作业抽查功能建设情况、抽查功能或评分项 `1.3`：现场调用 `score_calculate(module=special, dimension=functionBuild, itemNo=1.3)`，不得用总览结果替代。
- 用户问哪些项扣分、为什么扣分：调用 `special_score_drilldown`。
- 用户问哪张作业票有问题：调用 `special_ticket_issue`。
- 用户问指定编号原因：调用 `score_calculate`，按编号段传入对应维度。
- 所有上述工具最终只调用 Java `18082` 的评分接口；本轮范围不调用 `18083` 或其他扩展接口。
- 不输出原始 JSON、SQL、内部 URL、工具名或异常堆栈；无数据时说“暂未找到可用的评分数据”，接口失败时说“当前评分服务暂时不可用，请稍后重试”。
